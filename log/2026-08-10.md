# Wrap-Up — 2026-08-10

## Done
- Ran a full E2E browser test of the dashboard using the Chrome DevTools MCP (chrome-devtools MCP
  is configured and confirmed working in this project).
- Tested 10 user flows end-to-end in a real Chrome browser: unauthenticated redirect, login
  (empty, bad email, wrong password, correct credentials), pending assignments, routes + Leaflet
  map, route sidebar filter, create route, and export CSV.
- Found and fixed three bugs:
  1. **Pending assignments 500** — Supabase query joined `students` twice, PostgreSQL rejected it
     with "table specified more than once." Fixed: merged into a single join. Remote had also
     landed a fuller version of the same fix (commit 535d01f); resolved merge conflict by taking
     the remote's more complete field list.
  2. **Create Route school_id crash** — API passed `school_id` from request body, which the form
     never sent, causing a NOT NULL constraint error to render on screen verbatim. Fixed: API now
     queries the `schools` table and auto-inserts school_id server-side.
  3. **Export CSV 404** — `/api/export/csv` endpoint did not exist. Created
     `apps/api/src/routes/export.ts` with auth, optional `route_id` filter, and CSV streaming.
     Registered under `/api/export` in `app.ts`.
- All three fixes committed and pushed (commit a094684, branch main, up to date with origin).
